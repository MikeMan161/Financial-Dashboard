# Financial-Dashboard
This project is a financial dashboard. This is a full stack application

The Stack:
Frontend: FastAPI and Typescript
Backend: FastAPI and Python
Database: PostgreSQL
AI layer: Claude
Deployment: AWS (Elastic Beanstalk + RDS)
optional: FRED API for economic benchmarks

Key features: CSV upload or manual data entry
auto categorization using an LLM
natual language processing of your data
spending pattern detection and insights
optional economic benchmarks from fred api
